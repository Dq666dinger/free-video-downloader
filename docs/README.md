# 项目文档索引

这些文档用于沉淀一期开发结果，方便二期继续开发时快速接手，不需要再从代码里反向梳理。

## 推荐阅读顺序

1. [一期总结](./phase-1-summary.md)
2. [工程结构与数据流](./phase-1-architecture.md)
3. [接口契约](./phase-1-api-contract.md)
4. [二期接手说明](./phase-2-handoff.md)

## 文档定位

- `phase-1-summary.md`
  面向产品/项目进度，描述这期到底做了什么、没做什么、怎么验证的。
- `phase-1-architecture.md`
  面向研发接手，描述前后端目录职责、任务存储方式、下载链路和关键实现点。
- `phase-1-api-contract.md`
  面向联调，整理当前后端接口、字段、状态和错误行为。
- `phase-2-handoff.md`
  面向下一阶段开发，列出当前约束、已知风险、建议优先级和接续 checklist。
